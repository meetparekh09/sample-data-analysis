# Supermarket Sales Analysis

## Project Overview
This project analyzes supermarket sales data to understand sales trends and evaluate the performance of various features affecting sales. The analysis includes data preprocessing, model training, evaluation, and visualization of results.

## Features
- Load and preprocess sales data from a CSV file.
- Train a linear regression model to predict total sales.
- Evaluate model performance using metrics like RMSE and R² score.
- Visualize results including actual vs predicted sales, feature importance, and sales distribution.

## Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/supermarket-sales-analysis.git
   cd supermarket-sales-analysis
   ```

2. Generate the synthetic dataset:
   ```bash
   python random_generation.py
   ```

3. Run the main analysis:
   ```bash
   python main.py
   ```

4. Check the output visualizations and model performance metrics in the console.
